# 快捷指令单次自动化：未运行的设备实验

关联S-CALL-IOS-02与F-CALL-004。此处保存具体设备操作计划，没有生成或声称已安装一个签名`.shortcut`文件；目前暂无iPhone/受控接收端。

依据 [Apple个人自动化说明](https://support.apple.com/guide/shortcuts/enable-or-disable-a-personal-automation-apd602971e63/ios)，Time of Day可设置为自动触发，个别动作仍可能有自己的自动执行限制。此事实不证明Call动作在大陆锁屏免确认可用。

设备与接听方同意、接收端号码已确认后：

1. 在快捷指令创建一个仅用于该受控接收端的Call动作，保存名称`SalesDialer-OneShot-Probe`。不导入企业客户名单，不能把已提供的销售拨出号填成接收端。
2. 先人工运行，记录是否确认、所用SIM、双方声音、接收端显号、起止时间。拒绝/取消同样留证。
3. 创建Time of Day个人自动化，选当日未来2～3分钟的时刻，动作仅运行上述快捷指令；按当前系统界面选择立即运行或关闭运行前询问。记录机型、OS、地区、具体屏幕设置。
4. 一次实验结束立即关闭/删除此自动化，避免次日重复。分开测试前台、后台、锁屏、已有来电/通话、双卡默认线变化；每项重新明确启用一次。
5. 暂停验证需在快捷指令中关闭该自动化，并观察时刻到达不再执行。本原生app的暂停按钮不控制系统快捷指令，企业队列与取消同步仍未实现。
6. 分别记录触发是否发生、Call动作是否要求确认、实际呼出、接通、SIM/显号；提供设置截图、实际观察记录及可获取的系统日志。不能只以“自动化已运行”作为拨通证据。

不做长时间Wait、重复循环、静音音频保活或绕过系统确认。一次成功也不能证明200次日量、全天调度或自动下一条。若无需逐通确认且受控场景有证据，再另开集成实验定义任务控制、取消、状态关联与接续；未采纳降低自动化。
