# Wi-Fi使用说明（0.8版，无需日常USB连接）

手机与电脑连接同一可信Wi-Fi，电脑保持开机、不进入睡眠。电脑双击start-enterprise-wifi.cmd，保持后台服务运行；手机打开“销售拨号·受控试点”→企业账号与自动队列，使用原企业代码/销售账号登录。当前S23已配对并登录，可直接打开工作区；以后日常不运行prepare-s23-trial.cmd（该入口用于USB）。

1. 首次安装和本轮配对已完成。其他手机需先安装APK，再进入“电脑连接设置（Wi-Fi / USB）”，粘贴电脑.local/lan/pairing-code.txt中的配对码，确认配对后返回工作区登录。配对码包含连接凭据，只交给获准销售，不发到仓库或公开聊天。换连接会停止本机票据、清本批许可、重新登录，服务端未知记录保留。
2. 勾选合格名单，安排未来至少1分钟，点“确认本批并启动”并核对目标数和SIM。原规则保持：北京时间工作日09:00～18:00、每目标本批一次、挂断且填写明确结果后自动下一条、提交至少30秒间隔。
3. 挂断后点底部“有N通待核对 · 去填写结果”。不知道真实结果就记录未知并停止；不自动重拨。
4. Wi-Fi断开、电脑关机/休眠、服务停止或证书不匹配会阻止新提交；连接恢复也不会自动补拨。先刷新核对未知，再重新安排/确认，不连续重复点启动。
5. 结束先在手机暂停、核对并退出，再双击stop-enterprise-wifi.cmd停止Wi-Fi网关和原企业服务。暂停不等于挂断当前电话。

电脑首次配置命令：`pwsh -NoProfile -File tools/start-enterprise-wifi.ps1 -Address <电脑局域网IPv4>`；已配置后直接运行start-enterprise-wifi.cmd。地址必须为本机私有IPv4；本次证书有效期365天。电脑IP变动或证书到期时停止旧入口并重新配置/配对，不能关闭证书检查；可在路由器中为电脑保留固定地址。当前没有修改路由器或防火墙。若换网络被防火墙阻止，只开放所需局域网地址/端口，勿关闭整个防火墙。
