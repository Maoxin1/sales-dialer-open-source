## 准备名单

Excel第一行使用“电话、公司、姓氏”三个表头，顺序可调整；每行一位联系人。电话列设为文本，填写大陆11位手机号，不加空格、+86或公式。公司最多200字符，姓氏最多20字符，三列模式均须填写；姓氏支持复姓，不推断性别。

将含表头的三列从Excel复制到“名单→导入名单→名单内容”；或者另存为UTF-8 CSV后选择文件。模板见templates/contacts.csv，仅有表头，填写实际联系人后使用；不附虚构可误拨号码。支持CSV引号/逗号转义，不直接解析.xlsx。旧单列手机号逐行粘贴继续支持，旧联系人公司/姓氏为空。每批最多200条，非每日拨号上限。

## 导入与拨号

1. 填名单来源，按已有记录选择本批联系资格；选文件只载入，不自动导入。
2. 点“预览名单”，核对前5条掩码号码、公司与姓氏，再确认导入。改动内容/来源/资格会要求重新预览。
3. 系统报告成功、重复和逐行失败：格式错误/不支持、归其他销售或拒绝联系。手机号是去重依据；相同号码保留原公司、姓氏和资格，不静默覆盖，不新增资料编辑流程。
4. 勾选有资格的联系人→继续→设置时间→核对本批→手机原生明确确认。导入本身不创建队列或许可。工作时段、至少30秒间隔、结果明确后下一条、暂停/UNKNOWN不重放保持。
5. 结果卡与历史显示关联公司、姓氏、号码掩码；搜索支持尾号、公司和姓氏。
