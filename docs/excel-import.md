## 使用

1. 下载或复制templates/contacts.xlsx，在第一工作表填写“电话、公司、姓氏”。电话列已设文本；保持11位原值，不填公式。
2. 在“名单→导入名单→选择Excel / CSV文件”选择.xlsx；电脑可直接选择，手机用系统文档选择器。
3. 查看载入提示，填写来源和本批联系资格，点“预览名单”，核对号码掩码、公司、姓氏及条数后再确认导入。
4. 勾选合格联系人→继续→设置未来时间→核对本批→手机原生确认；挂断后填写真实结果。

Excel读取第一个工作表，首个非空行为表头，自动匹配电话/手机号/手机号码、公司/公司名称、姓氏（顺序可调），忽略其他列与全空行；读取后仍先预览、再确认导入，导入不安排或授权外呼。号码原值读取，不根据Excel显示格式猜改；建议电话列用文本，必须为大陆11位手机号。每批1–200条，非日量硬上限。公司/姓氏加密存储，去重/资格/时段/SIM/批次确认/未知恢复规则保持。

## 限制与错误处理

支持.xlsx（文件≤1MB），CSV仍≤300KB；Excel解压总量≤8MB、≤128个内部文件、工作表实际单元格/声明范围≤1000行64列。拒绝损坏/加密、宏/外部链接、XML实体、隐藏工作表及公式；请把目标名单复制为纯值到新的普通.xlsx。旧.xls请另存.xlsx。其他工作表不会作为导入目标；若要读其他表，请移到首表。

解析在手机/电脑本地页面完成，不上传Excel文件到第三方；只在确认导入后将三列资料提交原企业服务。文件读取失败不产生联系人、计划或许可。退出/登录失效清除导入草稿，迟到的文件回调不跨身份写回。原手机号重复不覆盖已有公司/姓氏，旧名单补填尚无编辑功能。

普通/共享字符串、数值手机号、空行/列重排/额外列/首表、公式/损坏/宏/实体/大展开/CRC/稀疏范围等已有软件证据；S23正常文件及取消实际通过。密码保护、超限/坏编码的全部手机文档提供程序组合未逐一真机测试，不扩称通过。当前S23支持所需解压能力；其他WebView若不支持deflate-raw会提示更新或转CSV。
