## 入口与行为

```powershell
node tools/close-enterprise-live-permit.mjs --permit-id "CONTROLLED-本次完整64位摘要"
```

必须传完整、明确的本次ID；不接受all、模糊匹配或强制清空。ID来自该次准备记录/私有许可文件，命令不需要完整手机号、密码、令牌或密钥参数。

准备与关闭共用项目私有互斥锁。先核对并撤销电脑端同一ID的许可，再核对已配置手机的用户、安装包、安装私有设备ID、许可ID和队列。只在手机匹配、没有另一条活动队列时强停本应用并移除同一ID的生效/待部署文件；不强停系统拨号器、不挂断已经呼出的电话。手机强停后，旧票据文件可能仍是原状态；重开由原生恢复逻辑禁用，不等于重新启动。

仅暂停许可对应的当前企业/销售队列，使用最新version；若已经被另一条队列替换，保持替代队列。没有结果写入、未知关闭、重拨、记录删除或次数重置操作。服务离线、文件删除失败、手机离线/身份不匹配/另一队列占用都明确报告未完成项。服务许可移除失败时仍尝试匹配手机停用和当前队列暂停，不因第一项失败而停止其余可完成的撤销。

共用文件库只删除本操作创建的临时文件；每次发布/删除校验当前锁PID/nonce。不删除别人的准备文件、历史、密钥、额度记录；不自动清除过期锁。

## 返回结果

| 结果 | 退出码 | 含义 |
|---|---|---|
| REVOKED | 0 | 本次许可已撤销，能识别的对应队列已处理；不代表已结束系统通话或已核对结果 |
| ALREADY_ABSENT | 0 | 本机和已配置手机未发现该许可；重复执行不补发、不改次数/结果；无范围信息时不随意暂停队列 |
| PARTIALLY_REVOKED | 1 | 已尽量完成撤销，unverified列明仍需核对的设备/服务/队列/锁状态，不能称完全关闭 |

若当前仍有系统电话，请销售正常挂断并核对。UNKNOWN保留到销售明确处理，API成功/停止工具成功不能充当接通或挂断证据。PARTIALLY_REVOKED时保持队列暂停，按unverified重新连接核查；不可为消除提示而删历史/重建密钥或清空额度。
