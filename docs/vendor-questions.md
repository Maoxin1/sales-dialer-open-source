# 线路/运营商询问草稿

日期：2026-10-14。对象优先为实际销售SIM归属地中国电信及必要的企业线路供应商。此文件是供mantou审阅/转发的草稿；Codex没有联系任何供应商、提交号码、开户或询价。

## 已知条件

企业内部销售、中国大陆客户、Android/iPhone、双卡；原第一阶段要求销售SIM主动拨出且客户看到销售手机号，接通由销售讲话。日量为每人约200次总尝试（含重拨），非200个不同号码，不要求全部接通。预算、人数、省份、套餐、接收端名单/联系依据未确定。用户报告现有拨出SIM为中国电信，受控测试同意已报告；线路和显号未实测。

## 公共资料目前能回答的部分

| 问题 | 能得到的结论 | 不能外推的部分 |
|---|---|---|
| Android能否请求SIM直接呼出/选账户 | 公开Telecom API存在直接请求与电话账户extra。[Android接口](https://developer.android.com/reference/android/telecom/TelecomManager) | API不保证个人套餐允许营销用途、后台可靠、约200次或正确显号。 |
| iPhone普通tel能否免确认 | 官方tel资料要求确认。[Apple Phone Links](https://developer.apple.com/library/archive/featuredarticles/iPhoneURLScheme_Reference/PhoneLinks/PhoneLinks.html) | 供应商说“兼容iPhone”不等于大陆个人SIM自动拨出；需明确链路与实际设备证据。 |
| 消费者商业电话/取消 | 国务院条例第24条规定同意、便捷取消与取消即停。[条例](https://app.www.gov.cn/govdata/gov/202403/19/513111/article.html) | 现有名单是否具备有效联系依据、是否纯B2B须按实际业务核对。 |
| 运营商合同是否涉及营销话音 | 广东电信官方索引摘要提及同意/拒绝相关限制，全文访问412，未全文核查。[地方协议线索](https://gd.189.cn/oper/agree/agreement.htm) | 不是用户实际归属地/套餐条款，未得到通用日量上限或已批准营销用途。 |

## 给实际SIM运营商的问题

| ID | 需要明确回答的问题 | 期望证据/责任 |
|---|---|---|
| V-CALL-001 | 用户所属省份及当前个人SIM套餐，能否用于企业销售商业联系？是否须企业套餐或登记用途？ | 实际适用入网协议、业务说明、书面确认、版本/地区及办理主体。 |
| V-CALL-002 | 每人每天约200次总尝试（含重拨），按通数/分钟/不同号码/呼叫间隔如何评估？有无小时、日、月及异常风控规则？ | 可公开阈值、适用条件、异常停机与恢复流程；未提供则记未知，不承诺稳定使用。 |
| V-CALL-003 | 两张卡同时启用、一次一通；选定中国电信SIM时客户是否看到该销售号码？漫游、携转、Wi-Fi Calling和来电占用有何影响？ | 受控接收端显号实测、主叫线路记录、适用设备/省份/网络。 |
| V-CALL-004 | 未接、忙线、拒接、留言、接通分别如何计费？计费起点、最小计费单位、套餐分钟、超额单价和跨省/漫游规则？ | 实际资费表及账单字段；总尝试与计费通话段分别估算。 |
| V-CALL-005 | 是否允许第三方手机app自动请求呼出？是否限制外呼设备、SIM盒、自动化软件或转售？ | 针对本原生app链路的条款与责任划分，不能只回答“号码能拨打”。 |
| V-CALL-006 | 联系取消、投诉、号码标记、风控停机、误封申诉怎样处理？软件方/企业/销售/运营商分别负责什么？ | 操作流程、工单入口、响应条件及所需证据。 |

## 若评估其他企业线路（改变原范围，待用户采纳）

| ID | 询问草稿 | 需警惕的证据缺口 |
|---|---|---|

| V-CALL-009 | Android/iPhone如何启动、后台/锁屏如何响应、销售未就绪/另一通占用怎样停止客户侧呼叫？ | 双端实际流程、权限/地区/版本、失败与取消证据。 |
| V-CALL-010 | 一人一通与企业总并发多少，限流、重拨、防重、未知结果核对如何保证？ | API幂等/任务ID、状态来源、异常恢复与计费账单关联。 |
| V-CALL-011 | 云回拨两个通话段、等待、固定语音、转接、录音/识别分别如何收费？ | 单价、计费起点/单位、最低消费、月租、接入费和退出费；未询价不填价格。 |
| V-CALL-012 | 后续固定语音怎样进入客户通话，意愿怎样判断、销售怎样接手，客户取消怎样立即停止？ | 实际媒体/转接方案与测试链路；本轮无音频注入成功结论。 |
| V-CALL-013 | 服务资质/业务用途、个人信息委托、存储地区、日志与录音期限、删除/导出、SLA、故障赔付和终止迁移？ | 合同、责任边界与可审计证据；供应商材料作为数据核验。 |
